Готовая нативная сборка для Ubuntu 20.04 x86_64. Системный Python менять не нужно.

Включены Python 3.12, скомпилированный модуль, зависимости, configNew.py CublayCraft,
иконки, общий веб-прогресс и ограничение RAM через cgroup v1/v2.
Исправлено чтение новых палитр Minecraft 26.3: строки, id/properties,
точные значения свойств по умолчанию и смешанные NBT-списки.

Скачайте именно файл CublayCraft-Overviewer-Ubuntu20.04-x86_64.tar.gz ниже.
Распакуйте его, положите миры в worlds/ либо измените пути в configNew.py.
Запустите ./START.sh. При отсутствии assets/client.jar он загрузит клиент 1.21.5;
для 26.3 используйте MINECRAFT_VERSION=26.3 ./START.sh.
Подробная инструкция START_HERE_RU.md находится внутри архива.

Запуск ./overviewer.py --config=./configNew.py -p=4 --memory-limit=8G сохранён.
Sudo используется для создания лимита; рабочие процессы получают ваш исходный UID.
Доступ к контроллеру памяти ядра обязателен. Ограничение cgroup v1 не проверялось
на реальном ядре целевого сервера; недоступный контроллер приводит к отказу запуска.
Автоматическое сокращение работников при OOM пока не реализовано.

Миры и игровые JAR в архив не включены. Источник исправления палитры подтверждён
тестовым рендером; пользователь также подтвердил работу патча на своём мире.
